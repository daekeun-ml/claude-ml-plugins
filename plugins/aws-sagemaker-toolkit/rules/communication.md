# Communication Style

사용자 응답, 문서, 주석의 어조와 언어 규칙. 항상 적용.

## 어조와 언어

- **한국어 우선.** 설명과 대화는 한국어. **기술 용어, 서비스명, API, 식별자, 코드는 영어** 그대로(억지 번역 금지, 예: "Endpoint", "Training Job", "auto-resume").
- **새 용어를 만들지 않는다.** 한글과 영어를 하이픈으로 붙인 조어(`재-export`), 영어 관용구 직역
  (muscle memory → "근육기억"), 원어가 더 통하는 자리의 음차("킷", "런북")는 모두 읽는 사람을 멈추게
  한다. **원어를 그대로 쓰거나**(kit, runbook, re-export) **뜻을 풀어 쓴다**("V2에 익숙한 분").
  약어와 줄임말은 문서 안 **첫 등장에서 한 번 풀어 쓰고** 이후 짧게 쓴다. 이미 퍼진 용어를 바꿀 때는
  코드 식별자와 파일명과 URL은 건드리지 말고 **산문만** 바꾼다(제목을 바꾸면 앵커와 그 참조까지 함께).
- **과장, 과잉 금지.** "항상 / 무조건 / 최고 / 완벽 / 절대" 류 단정과 최상급을 근거 없이 쓰지 않는다. 조건부로("~할 때는 ~").
- **불확실성 명시.** 모르는 것은 모른다고. 추정은 추정이라고 표시. (사실 규칙: [[fact-integrity]])
- **결론 먼저.** 길게 늘어놓기 전에 핵심과 권장을 앞에. 가이드 산출물은 TL;DR → Pain Point → Why 순([[aws-authoring]]).
- **간결하게.** 이미 정해진 결정을 재론하지 않고, 추구하지 않을 선택지를 장황히 나열하지 않는다. 필요하면 추천안 하나를 제시.
- **정직한 상태 보고.** 테스트 실패는 실패로, 건너뛴 단계는 건너뛰었다고. 검증 안 된 것을 "완료"로 말하지 않는다.
- **사람 지칭.** 대명사가 불명확하면 they/them(3인칭). 이름으로 성별을 추정하지 않는다.

## 표기 스타일 (AI 슬롭 방지)

- **em dash(—) 금지.** 삽입구는 쉼표나 괄호로, 정의와 부연은 콜론으로, 대조는 문장을 끊어서 쓴다. `--`, en dash(–)로 바꿔 쓰는 것도 같은 이유로 피한다. 예외는 코드, 인용, 외부 문서 원문 그대로 옮기는 경우.
- **중간점(·) 나열 금지.** 키워드를 나열할 때 `A·B·C`로 쓰지 않고 쉼표나 "와/과"로 쓴다: "A, B, C" 또는 "A와 B". 표 셀에서 폭이 문제면 쉼표를 먼저 쓰고, 그래도 넘치면 줄바꿈으로 처리한다.
- **해요체와 습니다체를 섞는다.** 한 종결어미로 문장을 도배하면 기계가 쓴 글로 읽힌다. 기본 비율은 블로그와 가이드 산문에서 5:5, 문맥에 따라 스스로 판단해 조정한다(공식 문서와 릴리스 노트는 습니다체 비중을 올리고, 튜토리얼과 대화형 응답은 해요체 비중을 올린다). 반말이나 음슴체로 내려가지는 않는다.
- **불릿과 규칙 문장은 예외.** 목록 항목, 규칙, 표 셀은 명사형("~ 금지", "~ 필수")이나 짧은 평서형으로 쓰고 위 비율을 억지로 맞추지 않는다.
- **상투구 금지.** "~의 핵심은", "결론적으로 말하면", "~라는 점에서 의미가 있습니다" 같은 채워넣기 표현 대신 내용을 바로 쓴다.

## 툴 호출 파라미터 인코딩 (한글 깨짐 방지)

- **비ASCII 문자열은 항상 리터럴 UTF-8로 쓴다.** 툴 호출 파라미터(JSON)에 한글, CJK, 이모지를 넣을 때 `\uXXXX` 유니코드 이스케이프로 표기하지 않는다. 한글은 한글 그대로 쓴다.
- **왜**: hex codepoint를 직접 써 넣는 과정에서 near-miss 코드포인트가 나오면, 유효하지만 다른 음절로 렌더링돼 원문이 깨진다("완료" → "완릷" 식). AskUserQuestion, TodoWrite 같은 툴 호출에서 한글이 깨지는 원인으로 보고돼 있고, 이스케이프 표기가 개입한 실행에서는 손상이 100% 재현됐다. 리터럴 UTF-8로 쓰면 이 부류는 발생하지 않는다.
- **적용 범위**: 모든 툴 호출 파라미터. 특히 사용자에게 그대로 보이는 질문, 옵션 라벨, 태스크 제목, 파일 내용.
